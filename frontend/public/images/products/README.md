## Image Specifications:
- Recommended size: 1200x1200 pixels (square) or 1200x800 pixels (landscape)
- Format: JPG or PNG
- File size: Keep under 500KB per image for optimal performance

## How to Add Images:
1. Save your product images with the exact filenames listed above
2. Place them in this directory: `frontend/public/images/products/`
3. The images will be automatically accessible at `/images/products/[filename]`
